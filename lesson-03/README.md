На каждое — примерно 5–10 минут. Используйте стандартную библиотеку.

Автотесты проверяют функции; вывод в `main` и ответы на вопросы проверьте сами.

## Ответы на вопросы

Задание 1. &number это адрес переменной number, а *value это значение, которое лежит по этому адресу. Go передаёт в функцию копию аргумента. Если передать просто число, функция изменит копию, а number в main останется прежним. Если передать адрес, функция меняет саму переменную. Если указатель nil, разыменовывать его нельзя, будет panic, поэтому сначала проверяем на nil.

Задание 2. При присваивании среза и при передаче в Sum копируется только сам срез: ссылка на массив, длина и ёмкость. Сами элементы не копируются, обе переменные смотрят в один и тот же массив. Поэтому изменение через shared видно и через numbers. Результат append нужно сохранять, потому что append возвращает новый срез с новой длиной, а иногда и с новым массивом. Если его не сохранить, добавленный элемент потеряется.

Задание 3. Если ключа нет, map возвращает 0, так же как для студента, у которого реально 0 баллов. Отличить их можно только через ok в score, ok := scores[name]: у Бориса ok будет true, у Глеба false. Если написать var scores map[string]int без make, map будет nil. Читать из неё можно, но первая же запись вызовет panic, поэтому map нужно создать через make до записи.
